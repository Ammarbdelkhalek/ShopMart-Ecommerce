# ShopMart - E-Commerce Web API 🛒

A backend RESTful API for an e-commerce platform built with ASP.NET Core.

## ✨ Features
- User Registration & Authentication (JWT)
- Product Management (CRUD)
- Categories & Brands
- Shopping Cart & Orders
- Role-based Authorization (Admin, User)

## 🧰 Technologies
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- AutoMapper
- Swagger

## 🚀 Getting Started
1. Clone the repo
2. Update `appsettings.json` with your DB connection string
3. Run migrations and update DB
4. Run the project
