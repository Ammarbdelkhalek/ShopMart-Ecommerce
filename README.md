# 🛒 ShopMart - E-Commerce Web API

A full-featured backend RESTful API for an e-commerce platform built with **ASP.NET Core**.  
This project demonstrates solid backend architecture, clean code structure, and common real-world features such as authentication, product management, and order handling.

---

## ✨ Features

- ✅ **User Authentication** (JWT)
- ✅ **Role-based Authorization** (Admin & User)
- ✅ **CRUD for Products, Categories, Brands**
- ✅ **Shopping Cart & Orders**
- ✅ **Entity Framework Core** with Code-First Migrations
- ✅ **Swagger UI** for easy API testing
- ✅ **Clean folder structure**

---

## 🧰 Technologies Used

| Stack         | Description                     |
|---------------|---------------------------------|
| ASP.NET Core  | Web API Framework               |
| EF Core       | ORM for Database Access         |
| SQL Server    | Relational Database             |
| Swagger       | API Documentation & Testing     |
| AutoMapper    | Object Mapping for DTOs         |
